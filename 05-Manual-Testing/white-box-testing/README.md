# White-box Testing

Pengujian struktur internal kode seperti statement/branch coverage, kondisi, jalur logika, dan unit test. Memerlukan source code, lingkungan lokal/staging, instruksi build, serta izin pemilik.

Jika source code tidak diberikan, dokumentasikan sebagai BLOCKED/not feasible. Jangan menyatakan white-box telah dilakukan hanya berdasarkan inspeksi browser.

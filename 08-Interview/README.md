# 08 — Interview

Wawancara ditujukan kepada QA Engineer/Software Tester dengan pengalaman profesional minimal 3 tahun.

Dokumen mencakup profil narasumber, pertanyaan, transkrip/ringkasan yang disetujui, serta bukti pelaksanaan dan persetujuan kutipan. Jangan mengarang identitas, pengalaman, jawaban, atau bukti wawancara. Lindungi data pribadi narasumber.

# 06 — Automation Testing

Kandidat alat: Playwright untuk UI; Postman/Newman untuk API bila akses diberikan. Pilih stack final setelah teknologi dan lingkungan IdBotani dikonfirmasi.

Jangan menjalankan test yang mengubah data atau membuat transaksi pada production. Gunakan staging/sandbox atau skenario read-only yang disetujui.

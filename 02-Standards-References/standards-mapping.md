# Standards Mapping — Draft

| Referensi | Peran dalam proyek | Status |
|---|---|---|
| ISO/IEC/IEEE 29119 series | Proses testing, dokumentasi, test design/test execution sesuai bagian yang relevan | Perlu verifikasi edisi/part resmi |
| ISO/IEC 25010:2023 | Model kualitas produk perangkat lunak | Identitas edisi ditetapkan; pemetaan karakteristik perlu disusun |
| IEEE references | Referensi pendukung sesuai topik | Belum dipilih dan diverifikasi |

## Catatan metodologis

ISO/IEC 25010:2023 merupakan model kualitas produk, bukan prosedur langkah demi langkah pelaksanaan testing. ISO/IEC/IEEE 29119 series lebih tepat sebagai rujukan proses dan dokumentasi testing.

ISO/IEC 27001 adalah standar sistem manajemen keamanan informasi. Jika digunakan, posisikan sebagai konteks tata kelola keamanan informasi, bukan pengganti standar proses software testing.

**Status:** draft pemetaan. Nomor part, judul, klausul, dan tahun setiap standar harus diperiksa dari katalog penerbit sebelum sitasi final.

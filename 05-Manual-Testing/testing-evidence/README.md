# Testing Evidence

Simpan bukti berdasarkan Test Case ID, misalnya:

```
testing-evidence/
  IDB-BB-001/
    step-01-homepage.png
    execution-notes.md
```

Setiap bukti harus mencatat tanggal, lingkungan, browser/perangkat, langkah, dan keterkaitan ke test case. Samarkan informasi pribadi. Evidence di sini terpisah dari bug report; bug report merujuk ke path evidence.

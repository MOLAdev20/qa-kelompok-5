# 04 — Test Cases

Berisi skenario, test case, dan test data.

- `test-cases.csv` — 18 test case (IDB-BB-001 s.d. 018)
- `test-flows.md` — 10 flow pengetesan end-to-end (FLOW-01 s.d. FLOW-10) berdasarkan test case di atas

Setiap test case setidaknya mencakup:
- Test Case ID
- Fitur/area
- Tujuan dan prasyarat
- Data uji
- Langkah pengujian
- Expected result
- Actual result
- Status
- Evidence reference
- Tester dan tanggal eksekusi

Gunakan status NOT RUN sampai test benar-benar dijalankan.

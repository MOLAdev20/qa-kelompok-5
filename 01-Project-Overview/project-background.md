# Project Background

## Latar belakang

Website marketplace memiliki beberapa alur yang saling berkaitan, mulai dari penelusuran katalog, pencarian produk, autentikasi, keranjang, pemesanan, hingga pengelolaan toko dan pelacakan pesanan. Kesalahan pada alur tersebut dapat menghambat pengguna atau menghasilkan informasi yang tidak konsisten.

IdBotani (https://idbotani.com/) menjadi kandidat objek evaluasi karena menyediakan website marketplace yang dapat diamati dari sisi pengguna. Penelitian ini dirancang untuk menilai fungsi dan kualitas produk perangkat lunak secara terstruktur.

## Alasan pemilihan objek

- Berbentuk aplikasi web yang dapat diamati.
- Domain marketplace memungkinkan penyusunan skenario pembeli dan pelapak.
- Memiliki beberapa area fungsional yang dapat dijadikan kandidat test case.
- Dapat menjadi studi kasus pengujian manual dan otomatis apabila akses dan izin tersedia.

## Hal yang belum diketahui

Skala organisasi, jumlah pengunjung, status operasional seluruh fitur, teknologi, pemilik sistem, dan ketersediaan source code belum terverifikasi. Informasi ini harus diperoleh melalui konfirmasi resmi, bukan asumsi.

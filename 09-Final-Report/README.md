# 09 — Final Report

Laporan akhir disusun setelah aktivitas selesai. Bagian minimal: pendahuluan/profil objek; standar dan kajian literatur; metodologi/test plan; hasil black-box, grey-box, white-box beserta batasan akses; hasil automation; defect, severity, priority, evidence; hasil wawancara QA; analisis kualitas, kesimpulan, keterbatasan, dan rekomendasi.

Jangan mengisi hasil dengan angka atau temuan yang belum didukung data aktual.

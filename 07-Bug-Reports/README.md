# 07 — Bug Reports

Setiap defect terkonfirmasi memiliki Bug ID dan merujuk ke Test Case ID serta evidence. Field minimum: judul, environment, precondition, langkah reproduksi, expected/actual result, severity, priority, evidence path, reporter, tanggal, status, dan retest. Evidence tetap disimpan di `05-Manual-Testing/testing-evidence/`.

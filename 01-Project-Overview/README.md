# 01 — Project Overview

Folder ini menjelaskan latar belakang, profil objek, tujuan, dan batasan penelitian.

Objek awal: website IdBotani (https://idbotani.com/).

Dokumen:
- `application-profile.md`: identitas dan fitur yang diamati.
- `project-background.md`: latar belakang dan alasan pemilihan.
- `scope-and-objectives.md`: tujuan, ruang lingkup, asumsi, dan batasan.

**Validasi wajib:** status badan usaha, skala usaha, jumlah pengguna/pengunjung, pengelola, dan tim pengembang belum boleh diasumsikan. Konfirmasikan kepada pihak IdBotani.

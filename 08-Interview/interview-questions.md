# Interview Questions — QA/Test Engineer

1. Ceritakan peran dan pengalaman profesional QA/testing Anda.
2. Bagaimana mengubah kebutuhan menjadi test scenario/test case?
3. Bagaimana memilih prioritas pengujian berbasis risiko?
4. Kapan black-box, grey-box, dan white-box digunakan?
5. Bagaimana menjaga traceability requirement ke test case?
6. Bagaimana menentukan severity dan priority defect?
7. Bagaimana memilih kandidat test untuk automation?
8. Tools apa yang digunakan untuk UI, API, dan unit testing? Mengapa?
9. Bagaimana mengelola test environment, test data, dan regression testing?
10. Apa tantangan umum menguji marketplace/e-commerce?
11. Metrik apa yang berguna untuk melaporkan kualitas?
12. Saran untuk tim mahasiswa yang menguji aplikasi web nyata?

Minta izin sebelum merekam, menyalin, atau mengutip jawaban.

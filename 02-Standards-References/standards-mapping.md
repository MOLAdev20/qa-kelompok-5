# Standards Mapping — IdBotani QA

| Referensi | Tahun | Peran dalam proyek | Status |
|---|---:|---|---|
| ISO/IEC/IEEE 29119-1 | 2022 | Konsep umum dan terminologi software testing | Terverifikasi dari katalog ISO |
| ISO/IEC/IEEE 29119-2 | 2021 | Proses testing untuk perencanaan, pengelolaan, dan eksekusi | Relevan, tetapi di luar batas tahun tugas |
| ISO/IEC 25010 | 2023 | Model kualitas produk perangkat lunak | Terverifikasi dari katalog ISO |
| ISO/IEC 25002 | 2024 | Panduan model kualitas SQuaRE | Terverifikasi dari katalog ISO |

## Pemetaan aktivitas

| Aktivitas proyek | Referensi utama | Artefak |
|---|---|---|
| Memahami konsep dan istilah testing | ISO/IEC/IEEE 29119-1:2022 | Glosarium dan metodologi |
| Merencanakan dan mengelola pengujian | ISO/IEC/IEEE 29119-2:2021, jika disetujui dosen | Test plan, jadwal, kriteria masuk/keluar |
| Mendesain dan melaksanakan test case | ISO/IEC/IEEE 29119 series; metode dipilih sesuai akses | Test scenario, test case, execution log |
| Menilai kualitas produk | ISO/IEC 25010:2023 | Quality model mapping dan indikator |
| Menjelaskan penggunaan model kualitas | ISO/IEC 25002:2024 | Dasar pemilihan model dan ukuran |

## Catatan metodologis
ISO/IEC 25010:2023 adalah model kualitas produk, bukan prosedur langkah demi langkah pelaksanaan testing. ISO/IEC/IEEE 29119 series lebih tepat sebagai rujukan software testing. ISO/IEC 25002:2024 memberi kerangka penggunaan model kualitas.

ISO/IEC/IEEE 29119-2:2021 merupakan standar proses yang relevan, tetapi publikasinya 2021. Karena instruksi tugas membatasi sumber dokumentasi pada 2022–2026, jangan menyatakan 29119-2:2021 memenuhi rentang itu. Minta persetujuan dosen untuk menggunakannya sebagai pengecualian atau gunakan sumber proses lain yang disetujui dan berada dalam rentang.

ISO/IEC 27001 adalah standar sistem manajemen keamanan informasi, bukan pengganti standar proses software testing.

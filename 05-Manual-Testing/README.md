# 05 — Manual Testing

Manual testing dipisahkan menjadi:
- `black-box-testing/`
- `grey-box-testing/`
- `white-box-testing/`
- `testing-evidence/`

Jalankan hanya pengujian yang diizinkan. Simpan screenshot terpisah dari defect log dan tautkan melalui Test Case ID. Jangan menyimpan data pribadi atau kredensial.
